## You understand what Java is, and what features are considered part of its core and what features are considered more advanced.

Core:
- Interfaces
- OOP
- Variables
- Classes
- Loops
- Inheritance
- Datastructures, Lists, Maps, etc
- Working with files

Advanced:
- Immutability
- Concurrency
- Dependency Injection
- Garbage Collection
- Design Patterns
- How JVM works
- Best Practices
- Threads
- Jackson

## You understand what a Java developer does and what skills you need as a Java developer.

Baiscally the skills for a Java developer are the same as any other kind of backend developer. Think Git, databases, microservices, CI/CD, cloud platforms like AWS, security, and so on.
The specific skills for a Java developer are Java, Spring Boot and the build tools Maven and Gradle.

## You know the different build tools and what the differences between them are.

From what I've read, Gradle is a better tool than Maven in almost every way, although Maven is simpler to use. Maven is recommended for small projects and Gradle is best for bigger projects. It is possible to migrate from Maven to Gradle.
